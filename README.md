# ReaperScythe

ReaperScythe is a Minecraft plugin that introduces an evolving scythe with enchantments, abilities, and lifesteal mechanics. The scythe gains power with each kill, offering unique abilities and visual effects to enhance gameplay. This plugin is designed for Spigot API 1.21.11 and requires Java 21.

## Install

1. Download the plugin JAR file from the [Releases](https://github.com/EnderDevelopment/ReaperScythe/releases) page.
2. Place the JAR file in the `plugins` folder of your Spigot server.
3. Restart or reload your server to load the plugin.

## Use

1. Join the server as an operator (OP) to receive the Reaper Scythe in your inventory.
2. Use the scythe to kill entities to increase its power level.
3. Unlock abilities at specific kill counts:
   - 2 kills: Shadow Burst (right-click to activate)
   - 4 kills: Reaper Traction (right-click to activate)
   - 6 kills: Crimson Wave (activate by placing the scythe in the off-hand)
4. At 10 kills, the scythe will steal a heart from the player you kill, increasing your maximum health.
5. Enjoy the visual effects of smoke and particles during attacks and abilities.
